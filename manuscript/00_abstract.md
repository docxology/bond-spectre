# Abstract

This report describes **{{SPECTRE_TITLE}}** (mission codename
**{{SPECTRE_CODENAME}}**), a special-agent mission-software package modelling
the global surveillance programme from the 2015 film *Spectre*. Working over
three analytic concepts, it (i) measures the centralization of a nine-agency
surveillance network whose data flows concentrate through hub agencies, (ii)
models the SPECTRE brotherhood as a compartmentalized criminal organization
with an isolatable command hierarchy, and (iii) analyzes the network's
geometry to identify the critical nodes whose neutralization most fragments
the system.
