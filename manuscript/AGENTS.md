# manuscript — Spectre NINE EYES

This directory holds the manuscript prose sections (`NN_*.md`) and
`config.yaml` for the Spectre / NINE EYES package.

## Token protocol

Every numeric/metric value in prose **must** use a `{{TOKEN}}`. Tokens are
computed by `src/spectre/manuscript_variables.py::generate_variables()` from
`manuscript/config.yaml` plus the *measured* output of the deterministic NINE
EYES mission provider — never hand-author a metric in prose.

Pipeline:
1. `scripts/z_generate_manuscript_variables.py` computes all tokens and writes
   `output/data/manuscript_variables.json`.
2. `resolve_manuscript_tree` copies each `NN_*.md` to `output/manuscript/`,
   substituting every `{{TOKEN}}` (strict mode fails on leftovers).
3. The live cross-reference gate in `tests/test_manuscript_variables.py`
   fails if any `{{TOKEN}}` in a `NN_*.md` section is missing from
   `generate_variables()`.

## Adding a token

1. Add a key to `generate_variables()` in `src/spectre/manuscript_variables.py`.
2. Reference it in prose as `{{MY_TOKEN}}`.
3. The live cross-reference test will verify full coverage.
